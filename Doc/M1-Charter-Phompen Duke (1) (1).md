## Gate 2 : MVP shape

FR: FR-1: Search and Select a Board Game The system shall allow users to search for and select a supported board game. FR-2: Learn Through Interactive Tutorial The system shall provide an interactive tutorial that explains game rules step by step. Users can ask the AI Tutor for additional explanations based on the game's rules. FR-3: Practice Game Situations The system shall provide simulated game situations where users can make decisions or choose actions. FR-4: Evaluate Player Decisions and Provide AI Feedback The system shall evaluate the user's decisions based on the game's rules and use AI to explain the result and provide appropriate feedback. FR-5: Complete Understanding Check and Track Progress The system shall provide rule-understanding checks and allow users to view their learning progress.

Which FR has actual logic or decision-making: FR-2, FR-3, and FR-4 involve actual logic and decision-making. The system retrieves relevant game rules, analyzes game situations and user decisions, and uses AI to provide explanations and feedback based on the game rules.

Gate 3 : Data / licence / systems that you depend on, and how do you know they’re actually accessible: The system will depend on board game rulebooks, an LLM API, and a database. The team will use accessible and permitted rulebook sources to build the game knowledge base and use an LLM API to explain rules and answer users’ questions. We will test the rulebook sources and API with a small prototype before development to confirm that they are accessible and usable.

Processes and Team SDLC : Agile We choose Agile because the team can develop the system incrementally, test features early, and improve the AI tutor and user experience based on user feedback.
