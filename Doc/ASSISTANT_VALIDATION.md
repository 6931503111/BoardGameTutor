# ผลตรวจผู้ช่วยกฎเกม 3 พฤศจิกายน 2026

## ขอบเขต

ปรับโค้ดและฐานข้อมูลในเครื่อง `D:\BoardGameTutor` สำหรับหกเกมที่มีอยู่ ไม่ได้ทดสอบทุกสถานการณ์ที่เป็นไปได้หรือรับรองทุกฉบับกล่อง มีคำตอบพื้นฐานที่ตรวจเทียบหลักฐานแล้ว 21 ข้อ การจับคู่คำถามกับคำตอบที่ตรวจแล้วกับการสร้างคำตอบสดเป็นคนละวิธี และแสดงป้ายกำกับบนเว็บ

## สิ่งที่เปลี่ยน

- เพิ่มการค้นด้วย multilingual embedding ใน Ollama (`embeddinggemma`) ร่วมกับการค้นคำ แคชเปลี่ยนตามเนื้อหาและค้นเฉพาะเกมที่เลือก
- เติมคู่มือ/บันทึกตรวจภาพคู่มือให้ห้าเกม Werewolf ยังใช้กฎพื้นฐานเพราะไม่ทราบฉบับ
- ตรวจและแก้เนื้อหา For Sale ที่นำเข้าผิด พร้อมข้อสอบ/สถานการณ์ให้ตรง IELLO EN V2 กติกาหลัก
- ใช้ `qwen3.5:4b` สำหรับถามตอบและจับคู่เจตนา ถ้าตั้ง env เองให้ตรวจโมเดลจริงจาก `/api/health`
- คำตอบตรวจแล้วใช้ได้ต่อเมื่อข้อความหลักฐานยังอยู่ มี alias แบบชัดเจน และจับคู่คำถามที่เปลี่ยนถ้อยคำได้โดยแสดงคำถามต้นแบบ ตรวจเป้าหมาย/จำนวนก่อนจับคู่
- คำนวณเปรียบเทียบราคาประมูลและคืนครึ่งหนึ่งปัดลงโดยตรง เฉพาะเมื่อมีข้อความกฎรองรับ ไม่ผูกเงื่อนไขกับชื่อเกม
- แยกบทสนทนาตามเกม ไม่ใช้ข้อความรุ่นฐานความรู้เก่าเป็นบริบท รักษาเป้าหมายใหม่ของคำถามต่อเนื่อง
- หากตรวจคำตอบสดไม่ผ่าน แสดงข้อความกฎพร้อมสถานะ excerpt แทนการแสดงข้อสรุปที่ถูกปฏิเสธ
- เพิ่มหน้าผู้ดูแลสำหรับแนบคู่มือ ระบุฉบับ ตรวจความครบทุกเกม และเพิ่มคำตอบที่ตรวจเอง

ไฟล์ผลรอบก่อนปรับเก็บแยกไว้เพื่อให้เห็นปัญหาจริง พบทั้งคำตอบกลับด้านและข้อความขัดกันเองแม้ตัวตรวจโมเดลยอมรับ จึงเพิ่มคำตอบตรวจแล้วและการจับคู่เจตนา **ไม่ควรตีความว่าการตรวจซ้ำด้วยโมเดลรับประกันข้อเท็จจริงทุกประโยค**

การจับคู่เจตนายังพึ่งโมเดล อาจเข้าใจคำถามต่างจากผู้ใช้ได้ จึงแสดงคำถามต้นแบบให้ตรวจ คำถามนอกฐานข้อมูลและภาคเสริมที่ไม่มีคู่มือต้องแจ้งข้อจำกัด การเพิ่มเกมใหม่ต้องตรวจข้อความและทดสอบเองก่อนเผยแพร่

## แก้คำถามเงินเริ่มเกมถูกจับคู่เป็นเงินคืน

พบจากการใช้งานจริงว่าเมื่อถาม “บอกผ่านประมูลจะได้เงินคืนเท่าไร” แล้วเปลี่ยนเป็น “เงินเริ่มเกมจะมีกี่เท่าไหร่” ตัวจับคู่เดิมอาจเลือกคำตอบเก่า เพราะคำถามภาษาไทยล้วนผ่านตัวกรองชื่ออังกฤษ/ตัวเลขทั้งคู่ และโมเดลยังได้รับบทสนทนาเก่าทั้งหมด

เพิ่มตัวกรองหัวข้อภาษาไทยก่อนนำคำตอบตรวจแล้วกลับมาใช้ คำร่วมทั่วไปเพียงคำเดียวไม่เพียงพอ คำถามที่ไม่มีสัญญาณถามต่อไม่ส่งประวัติเก่าเข้าโมเดล และการค้น semantic ใช้คำถามปัจจุบันก่อน ส่วนหลักฐานสำหรับคำถามต่อเนื่องยังมาจาก resolve_context ค้นคำถามที่ตรวจแล้วจากฐานความรู้ทั้งเกมเพื่อไม่ให้ตกหล่นเมื่อจำกัดจำนวนข้อความหลักฐาน

ตรวจภาพตารางเตรียมเกมจากคู่มือ For Sale IELLO EN V2 หน้า3 และเพิ่มหัวข้อภาษาไทย: ธนบัตรใบละ $1,000; เล่น3/4/5/6คน แจกคนละ28/21/16/14ใบตามลำดับ ไม่เพิ่มคำตอบสำเร็จรูปสำหรับคำถามที่รายงาน เพื่อทดสอบเส้นทางค้นกฎและสร้างคำตอบจริง

หลังแก้ Python tests 81 รายการผ่าน ครอบคลุมการกันเงินเริ่มเกมออกจากคำตอบเงินคืน การเปลี่ยนหัวข้อในประวัติเดิม การรักษาคำถามต่อเนื่องที่เปลี่ยนเป้าหมาย และการรักษาคำถามภาษาไทยที่เป็นถ้อยคำต่างกันแต่ยังถามเรื่องเดียวกัน ผลทดสอบบริการจริงอยู่ `state/topic-change-verification.json` รอบก่อนเพิ่มหน่วยเงินต้นฉบับอยู่ `state/topic-change-verification-before-currency.json` คำถามเงินเริ่มเกมได้ตารางจำนวนเงินจากกฎ R3 ผ่านวิธี model และไม่คืนคำตอบบอกผ่าน

สำหรับคำถามต่อเนื่องรูป “แล้วใช้กับ C ล่ะ” สามารถแทนเป้าหมายตัวสุดท้ายในคำถามอนุญาตก่อนหน้าเพื่อค้นคำตอบตรวจแล้วแบบตรงคำถามเท่านั้น หากไม่มีคำตอบที่ตรวจไว้ตรงกัน จะไม่สร้างกฎจากแม่แบบนั้น การยืนยันหลักฐานเดิมยังต้องผ่านทุกครั้ง ไม่ใช้การเปลี่ยนคำนี้กับคำถามที่ไม่มีผู้กระทำ/เป้าหมายชัดเจน
