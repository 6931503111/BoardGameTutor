# การเตรียมผู้ช่วย AI — 9 พฤศจิกายน 2026

เพิ่มความพร้อมด้วยตัวอย่างคำถามสำหรับค้นข้อมูลและปรับการกำหนดหลักฐาน ไม่ได้ fine-tune น้ำหนักโมเดล และไม่ได้เพิ่มคำตอบที่ AI สร้างเป็นคำตอบที่มนุษย์ตรวจแล้ว

## สิ่งที่ติดตั้ง

- ตัวอย่างคำถามภาษาไทย 105 ข้อ ครอบคลุมหกเกม: การเตรียมเกม การจั่ว/ลงไพ่ บทบาท การจับโกง ข้อยกเว้น การประมูล การขาย คะแนน และเงื่อนไขจบเกม
- คำถามทดสอบอีก 35 ข้อ ไม่ถูกติดตั้งเป็นคำค้น ตัวอย่างทั้งหมดอยู่ใน `backend/assistant_question_bank.json`
- ตัวอย่างคำถามเป็นข้อมูลช่วยจัดอันดับเท่านั้น ไม่ถูกส่งเป็นข้อความหลักฐานหรือคำตอบ และไม่เปลี่ยนกฎ คู่มือ บทเรียน หรือคำตอบตรวจแล้ว 21 ข้อเดิม
- ทุกกลุ่มผูกกับ SHA-256 ของชื่อและเนื้อหาหัวข้อกฎ หากแก้ข้อความใดในหัวข้อนั้นจะหยุดใช้คำค้นเก่าจนตรวจความสัมพันธ์ใหม่
- การค้น semantic ให้คะแนนข้อความคำถามเป็นหน้าต่างแยก และเก็บข้อความอ้างอิงเดิมครบหัวข้อ
- ใช้ลำดับที่รวมผลค้นคำและความหมายก่อน เติมผลค้นจากบริบทตามหลัง เพื่อป้องกันบทสรุปที่มีคำคล้ายกันเบียดคู่มือที่ตรงประเด็นออกจากบริบท
- JSON schema ของคำตอบ ตัวจับคู่ และตัวตรวจคำตอบ จำกัดรหัสอ้างอิงให้เป็นรายการหลักฐานปัจจุบัน การตรวจรหัสและข้อความอ้างอิงหลังตอบยังทำงานตามเดิม

## ผลค้นด้วยคำ

วัดว่าหัวข้อเป้าหมายที่ระบุไว้ปรากฏในห้าอันดับแรกหรือไม่ โดยปิดส่วน semantic ในการวัดนี้ ใช้ทั้งชุดก่อนและหลังกับข้อมูลกฎชุดเดียวกัน

| ชุด | จำนวน | ก่อนเพิ่มคำค้น | หลังเพิ่มคำค้น |
|---|---:|---:|---:|
| ตัวอย่างเตรียมข้อมูล | 105 | 54 | 105 |
| ถ้อยคำทดสอบที่แยกไว้ | 35 | 19 | 28 |

28/35 เท่ากับ 80% ในการค้นหัวข้อเฉพาะชุดนี้ **ไม่ใช่ความแม่นยำคำตอบ 80%** บางคำถามอาจพบข้อความกฎเดียวกันในหัวข้ออื่นซึ่งเกณฑ์นี้ไม่นับ ไม่ได้แก้คำค้นเพื่อไล่ให้ครบคำถามทดสอบทั้ง 35 ข้อ

ผลละเอียดอยู่ `state/assistant-preparation-report.json` มี source ID ก่อน/หลังทุกข้อ การตรวจนี้ทำซ้ำได้ด้วย `python -m scripts.prepare_assistant` โดยไม่เขียนฐานข้อมูล

## การตรวจโมเดลจริง

ใช้ Ollama `qwen3.5:4b` และ `embeddinggemma` บนเครื่องนี้ เลือกคำถามที่แยกไว้หนึ่งข้อต่อเกม ไม่ได้ใช้ mock โมเดล ผลดิบล่าสุดอยู่ `state/assistant-live-audit.json` และผลก่อนเพิ่มข้อจำกัดรหัสอ้างอิงอยู่ `state/assistant-live-audit-before-citation-constraint.json`

รอบก่อนปรับพบคำถาม Werewolf ถูกปฏิเสธเพราะรหัสอ้างอิงไม่ตรง, Mogel Motte ตอบจำนวนไพ่ถูกแต่แจ้ง partial เกินจำเป็น และ Exploding Kittens/For Sale ใช้เวลาจนหมดเวลา จึงเพิ่ม enum ของรหัสหลักฐานและปรับลำดับค้น แล้วลองหกเกมซ้ำ

รอบล่าสุด Werewolf ตอบบทบาทผู้ดำเนินเกมได้ และ Mogel Motte ตอบแจกคนละ 8 ใบโดยใช้ answered; Spyfall ใช้คำตอบตรวจแล้วตอบข้อห้ามถามกลับได้ คำต้องห้ามตอบใจความเรื่องรูปแบบและเวลารอบได้แต่ยังมีข้อความเกินคำถาม/ข้อจำกัดไม่จำเป็น จึงยังไม่ควรตีความว่าทุกคำตอบผ่านการตรวจเนื้อหา ผลและเวลาของแต่ละข้อให้ดูไฟล์ดิบ ไม่แปลงสถานะ answered เป็นคะแนนความถูกต้องอัตโนมัติ

| เกม / คำถามทดสอบล่าสุด | ผลที่สังเกต | เวลา |
|---|---|---:|
| Werewolf / ผู้ดำเนินเกมอยู่ฝ่ายชาวบ้านหรือไม่ | answered: ไม่ใช่ผู้เล่นในฝ่ายใด | 51.17 วินาที |
| Mogel Motte / แจกไพ่คนละเท่าไร | answered: 8 ใบ | 23.09 วินาที |
| คำต้องห้าม / ต้องตกลงอะไรก่อนเริ่ม | partial: ตอบรูปแบบและเวลารอบ แต่เพิ่มข้อจำกัดเกินคำถาม | 36.25 วินาที |
| Spyfall / ถามคนเดิมกลับทันทีได้หรือไม่ | answered จากคำตอบตรวจแล้ว: ไม่ได้ | 5.60 วินาที |
| Exploding Kittens / ดูอนาคตแล้วสลับไพ่ได้หรือไม่ | หมดเวลารอโมเดล ยังไม่มีคำตอบให้ตรวจ | 75.37 วินาที |
| For Sale / เงินเริ่มต้นเมื่อเล่น 5 คน | answered: คนละ 16 ใบ ใบละ $1,000 รวมคนละ $16,000 | 83.46 วินาที |

สรุปสถานะที่ API ส่งกลับ: answered 4, partial 1, timeout 1 จากหกกรณี ไม่ใช่คะแนนสอบความแม่นยำของโมเดล รอบล่าสุด For Sale กลับมาตอบได้ ส่วน Exploding Kittens ยังเป็นข้อจำกัดที่ต้องแจ้งไว้

## ทดสอบและเปิดใช้

Python suite เดิม 81 รายการและ regression เพิ่ม 8 รายการ รวม 89 รายการ ครอบคลุมการไม่ปนคำค้นเป็นหลักฐาน การหยุดใช้คำค้นหลังแก้กฎ การรักษาข้อมูลผู้ดูแล การติดตั้งซ้ำ การจำกัดรหัสอ้างอิง และการไม่ให้ผลค้นด้วยคำเบียดคู่มือที่เกี่ยวข้อง JavaScript 18 รายการตรวจแชต/คำตอบตรวจแล้ว/PDF-OCR/แบบทดสอบ

ข้อมูลค้นติดตั้งลง `backend/data/games.sqlite3` แล้ว สำรองก่อนเขียนด้วย SQLite backup API ชื่อ `games-before-ai-preparation-*.sqlite3` การติดตั้งเป็น transaction เดียวและไม่แก้วันปรับปรุงเกม ใช้ `python -m scripts.prepare_assistant --apply` เมื่อต้องติดตั้งใหม่; เพิ่ม `--live-limit 6` เพื่อทดสอบจริงหนึ่งข้อต่อเกม ผลทดสอบสดเป็นการสังเกต ไม่มีการสร้างคำตอบอนุมัติอัตโนมัติ

เปิดใช้โค้ดใหม่บนพอร์ต 8000 แล้วตามคำสั่งผู้ใช้ โดยส่งต่อ environment จากโปรเซสเดิมในหน่วยความจำ ไม่แสดงหรือบันทึกรหัสผ่าน ตรวจการเข้าสู่ระบบด้วยรหัสเดิมสำเร็จและออกจาก session ทดสอบทันที ผู้ดูแลต้องเข้าสู่ระบบใหม่เพราะ token ก่อนรีสตาร์ตหมดอายุ ตรวจหน้าเว็บ Backend Ollama และโมเดลพร้อมทั้งหมด และทดลองค้นผ่าน API จริงครบหกเกมได้หัวข้อเป้าหมาย ผลเปิดใช้อยู่ `state/ai-activation-check.json`
