## เปิดระบบ

1. เปิด PowerShell ที่ `D:\BoardGameTutor`
2. รัน `powershell -File .\scripts\Start-Presentation.ps1`
3. เข้า <http://127.0.0.1:5500> แล้วกด Ctrl+F5
4. รัน `python .\scripts\presentation_check.py` เพื่อตรวจหน้าเว็บ Backend Ollama และโมเดลที่ Backend ใช้จริง

หากคำสั่ง `python` เปิด Microsoft Store ให้ใช้ executable นี้แทน:

```powershell
& 'C:\Users\lfxxlk\AppData\Local\Python\pythoncore-3.14-64\python.exe' -X utf8 scripts/presentation_check.py
```

สคริปต์เปิดเฉพาะบริการที่ยังไม่ทำงาน และไม่ปิดบริการเดิม หากมี Backend เก่าที่ไม่ได้เปิด `--reload` ต้องเปิดใหม่ด้วยโค้ดล่าสุดก่อน วันทดสอบนี้บริการใช้โมเดล `qwen3.5:4b` และ `embeddinggemma` ซึ่งติดตั้งไว้ในเครื่องแล้ว ตั้ง `BGT_ASSISTANT_MODEL` เพื่อเปลี่ยนโมเดลถามตอบก่อนเริ่ม Backend ได้ โมเดลสร้างร่างเกมยังแยกเป็น `qwen3:1.7b`

สคริปต์อาจถามรหัสผู้ดูแลหากต้องเริ่ม Backend ใหม่และยังไม่ตั้ง `BGT_ADMIN_PASSWORD` ใช้รหัสที่คุณตั้งสำหรับรอบนั้น เข้าระบบผู้ดูแลใหม่หลังรีสตาร์ต Backend เพราะ token เดิมหมดอายุ

การถามตอบจากข้อมูลที่เตรียมไว้และโมเดลทำในเครื่อง ส่วนการอ่าน PDF สแกนด้วย OCR ครั้งแรกยังต้องใช้อินเทอร์เน็ตโหลดเครื่องมือ/ข้อมูลภาษา ก่อนสาธิตนำเข้า PDF ให้ลองอ่านไฟล์นั้นไว้ก่อน

## เพิ่มเกมหรือแก้ข้อมูลก่อนสาธิต

1. ผู้ดูแล → นำเข้า PDF → ตรวจข้อความ OCR โดยเฉพาะตัวเลข/คำปฏิเสธ/คอลัมน์
2. ตรวจร่างบทเรียน กฎ สถานการณ์และข้อสอบ ก่อนบันทึกและเผยแพร่
3. ใส่คู่มือ ชื่อฉบับ และ URL ใน “คู่มือสำหรับผู้ช่วย AI” สำหรับเกมเดิมได้
4. เพิ่มคำตอบที่ตรวจเองพร้อมคัดหลักฐานใน “คำตอบที่ตรวจเทียบกฎแล้ว” คำถามที่ความหมายเปลี่ยนต้องแยกกัน อย่าใส่เป็น alias
5. ทดลองคำถามปกติ คำถามปฏิเสธ คำถามตัวเลข คำถามต่อเนื่อง และคำถามที่ไม่มีในคู่มือ
6. เปิด “ตรวจข้อมูลผู้ช่วย AI ทุกเกม” ดูสิ่งที่ยังขาด

คำถามที่ผู้ดูแลตรวจไว้จะหยุดใช้เมื่อแก้แหล่งกฎจนข้อความที่คัดไว้หาย การสนทนาเก่ายังแสดงให้อ่าน แต่ข้อความที่มีรุ่นฐานความรู้เก่าจะไม่ถูกส่งเป็นบริบทให้โมเดลต่อ

## เก็บงานและแก้ปัญหา

ข้อมูลเกม คู่มือ คำตอบตรวจแล้วและรูปที่เพิ่ม เก็บใน `backend/data/games.sqlite3` ซึ่ง Git ไม่เก็บ ต้องนำฐานข้อมูลนี้ไปด้วยหากย้ายเครื่อง สำรองล่าสุดด้วย `python scripts/backup_games.py` ใช้ SQLite backup API จึงสำรองระหว่างบริการทำงานได้ ไฟล์สำรองอยู่ใน `backend/data/` ชื่อมีวันที่และเวลา

- เข้าเว็บไม่ได้: ตรวจพอร์ต 5500 และรันสคริปต์เปิดระบบ
- ถาม AI ไม่ได้: ตรวจ Backend พอร์ต 8000 และ Ollama พอร์ต 11434 ด้วยสคริปต์ตรวจบริการ
- โมเดลไม่พบ: ตรวจชื่อที่ Backend รายงานใน `/api/health` ให้ตรงกับ `ollama list`
- โหลดหน้าแล้วไม่เห็นการแก้: Ctrl+F5; ตรวจว่ากำลังเปิด localhost5500 ของโปรเจกต์นี้
- ข้อมูลไม่พอ: เปิดอ้างอิง ตรวจฉบับและคู่มือ เพิ่มหลักฐานแทนการบังคับให้ AI เดาคำตอบ
- หลังเปลี่ยนเกม บทสนทนาแยกตามเกม หากต้องการเปลี่ยนสถานการณ์ทั้งหมดใช้ “เริ่มบทสนทนาใหม่”

ผลตรวจจริงและขอบเขตอยู่ใน `Doc/ASSISTANT_VALIDATION.md` และผลดิบใน `state/presentation-*.json`
