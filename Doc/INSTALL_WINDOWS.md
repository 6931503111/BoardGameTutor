# ติดตั้ง BoardGameTutor บนเครื่องเพื่อน (Windows)

แพ็กนี้รวมโค้ดล่าสุด ฐานข้อมูลเกม คู่มือที่ใช้เตรียมข้อมูล และคำตอบที่ตรวจไว้แล้ว งานเตรียมฐานความรู้ไม่ต้องทำใหม่ ไม่รวม Python, Ollama, ไฟล์โมเดล, `.venv` หรือข้อมูลแชต/ความคืบหน้าจากเบราว์เซอร์ของเครื่องต้นทาง

## ติดตั้งครั้งแรก

1. ติดตั้ง Python install manager จาก https://www.python.org/downloads/ ตามคู่มือ Windows: https://docs.python.org/3.14/using/windows.html ให้ใช้คำสั่ง `py` ได้
2. ติดตั้ง Ollama สำหรับ Windows จาก https://ollama.com/download/windows แล้วเปิด Ollama
3. แตก ZIP จะได้โฟลเดอร์ `BoardGameTutor` เปิด PowerShell ในโฟลเดอร์ที่มีไฟล์ `Start-BoardGameTutor.cmd`
4. สร้าง Python environment ของเครื่องนี้และติดตั้งไลบรารี:

```powershell
py install 3.14
py -3.14 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r backend\requirements.txt
```

ถ้ามี Python 3.14 ติดตั้งอยู่แล้ว ข้ามบรรทัด `py install 3.14` ได้ ไม่ต้อง Activate environment ตัวเปิดระบบจะเลือก `.venv` ของโปรเจกต์ก่อน

5. ดาวน์โหลดโมเดลครั้งแรก:

```powershell
ollama pull qwen3.5:4b
ollama pull embeddinggemma
ollama pull qwen3:1.7b
```

สองตัวแรกใช้ถามตอบและค้นข้อมูล ส่วน `qwen3:1.7b` ใช้สร้างร่างเกม/แบบฝึกในหน้าแอดมิน โมเดลต้องใช้อินเทอร์เน็ตและพื้นที่หลาย GB ในขั้นนี้

6. ดับเบิลคลิก `Start-BoardGameTutor.cmd` ตั้งรหัสผู้ดูแลของเครื่องเพื่อนเมื่อระบบถาม รหัสเดิมของเครื่องต้นทางไม่ได้อยู่ในแพ็ก
7. หน้าเว็บเปิดที่ http://127.0.0.1:5500 หากยังไม่เปิดให้เปิด URL นี้เอง

เมื่อเปิดฐานข้อมูลจากแพ็กแล้ว เกมที่เตรียมไว้ควรแสดงทันที ไม่ต้องนำเข้าเกมตัวอย่างทับหรือสร้างฐานความรู้ใหม่

## เปิดใช้ครั้งต่อไป

เปิด Ollama แล้วดับเบิลคลิก `Start-BoardGameTutor.cmd` ใช้ได้จากตำแหน่งที่แตกไฟล์ ไม่จำเป็นต้องเป็นไดรฟ์ D หากเริ่ม Backend ใหม่ ระบบจะถามรหัสผู้ดูแลสำหรับรอบนั้นอีกครั้งถ้ายังไม่ได้ตั้ง `BGT_ADMIN_PASSWORD` ใน environment

ตรวจบริการได้ด้วย:

```powershell
.\.venv\Scripts\python.exe -X utf8 scripts\presentation_check.py
```

## ย้ายโมเดลเดิมแทนการดาวน์โหลด

ชื่อ tag ของโมเดลอาจอัปเดตได้ รุ่นที่ตรวจบนเครื่องต้นทางบันทึกใน `RUNTIME_VERSIONS.json` หากต้องการใช้ไฟล์โมเดลตรงกับต้นทาง ให้ปิด Ollama บนเครื่องปลายทางก่อน แล้วคัดลอกโฟลเดอร์ `%USERPROFILE%\.ollama\models` ของเครื่องต้นทางไปยังตำแหน่งเดียวกันของบัญชีผู้ใช้เครื่องเพื่อน จากนั้นเปิด Ollama และตรวจ `ollama list` วิธีนี้ใช้พื้นที่หลาย GB และเป็นทางเลือกแทนขั้น `ollama pull` ไม่ต้องทำทั้งสองวิธี

ตำแหน่งดังกล่าวเป็นค่าเริ่มต้นของ Windows หากตั้ง `OLLAMA_MODELS` ไว้ ให้ใช้ตำแหน่งที่ตั้งนั้น การคัดลอกไปเครื่องที่มีโมเดลอยู่แล้วควรเก็บสำเนาของเครื่องปลายทางไว้ก่อน ไม่ต้องส่งไฟล์โมเดลกลับมาที่แชต

## ขอบเขตและแก้ปัญหา

- ความเร็วขึ้นกับเครื่องเพื่อน คำถามใหม่อาจใช้เวลาหลายสิบวินาที และการถามครั้งแรกอาจต้องสร้าง embedding cache ใหม่ แพ็กไม่คัดลอกเวกเตอร์เก่าเพื่อป้องกันการใช้เวกเตอร์จากโมเดลคนละรุ่น
- ถ้าคำสั่ง `py` หรือ `ollama` ไม่พบ หลังติดตั้งให้ปิดแล้วเปิด PowerShell ใหม่ ตรวจ Python install manager และการเพิ่มคำสั่งลง PATH ตามคู่มือทางการ
- หากขึ้นว่าไม่มีโมเดล ใช้ `ollama list` ตรวจว่ามีชื่อครบตามขั้นติดตั้ง
- `.venv` ต้องสร้างบนเครื่องเพื่อน ไม่คัดลอกของเครื่องต้นทาง
- หลังเปิดบริการครบแล้ว การถามตอบใช้โมเดลและข้อมูลในเครื่อง การโหลดฟอนต์ การเปิดลิงก์คู่มือ และ OCR ครั้งแรกบางส่วนยังใช้อินเทอร์เน็ต
- รันแบบ localhost ตามที่เตรียมไว้ การให้หลายเครื่องเข้าใช้ผ่านเครือข่ายเป็นการตั้งค่าคนละแบบกับแพ็กนี้
