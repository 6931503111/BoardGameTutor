# BoardGameTutor

## Backend ฐานข้อมูลเกม (ระยะเริ่มต้น)

ระยะนี้ใช้ FastAPI และ SQLite สำหรับพัฒนาในเครื่อง ข้อมูลเกมที่สร้างหรือแก้ไขจากหน้าแอดมินจะถูกบันทึกที่ `backend/data/games.sqlite3` เกมตัวอย่างเริ่มต้นอยู่ในหน้าเว็บและนำเข้าได้จากหน้าแอดมิน

### เริ่มระบบในเครื่อง

ติดตั้ง dependencies จากโฟลเดอร์รากของ repository:

```powershell
python -m pip install -r backend/requirements.txt
```

กำหนดรหัสผ่านผู้ดูแลสำหรับหน้าต่าง PowerShell ปัจจุบัน แล้วเปิด Backend:

```powershell
$env:BGT_ADMIN_PASSWORD = "ตั้งรหัสผ่านที่คาดเดายาก"
python -m uvicorn backend.app:app --reload --host 127.0.0.1 --port 8000
```

อย่าใส่รหัสผ่านจริงลงใน source code หรือ commit ไฟล์ที่มีรหัสผ่าน

เปิดเว็บสถิตในหน้าต่าง PowerShell ที่สอง:

```powershell
python -m http.server 5500 --directory Code
```

จากนั้นเปิด `http://127.0.0.1:5500` ในเบราว์เซอร์ หน้าเว็บบน localhost จะเชื่อม Backend ที่ `http://127.0.0.1:8000` อัตโนมัติ

หลังเข้าสู่ระบบผู้ดูแล ให้กด **นำเข้าเกมตัวอย่างลงฐานข้อมูล** ในหน้าจัดการเนื้อหา เกมตัวอย่างที่ยังไม่มีจะถูกเพิ่มเข้า SQLite; เกมที่มีรหัสเดิมในฐานข้อมูลจะถูกข้ามและไม่ถูกเขียนทับ การนำเข้าซ้ำจึงปลอดภัย

### สร้างฉบับร่างเกมด้วย AI

ติดตั้งและเปิด Ollama บนเครื่องที่รัน Backend จากนั้นดึงโมเดลที่ต้องการ โมเดลเริ่มต้นคือ `qwen3:1.7b`:

```powershell
ollama pull qwen3:1.7b
```

เมื่อเปิด Backend ให้ตั้งค่า URL และชื่อโมเดลได้ด้วย `BGT_OLLAMA_URL` และ `BGT_OLLAMA_MODEL` (ค่าเริ่มต้นคือ `http://127.0.0.1:11434` และ `qwen3:1.7b`) ในหน้าแอดมินใส่ชื่อเกม วางข้อความกติกาอย่างน้อย 50 ตัวอักษร แล้วกด **ให้ AI สร้างร่างเกม** ระบบจะพยายามรักษารายละเอียดและแยกความสามารถของตัวละครทุกตัวตามต้นฉบับ โดยจัดกฎก่อนบทเรียนและข้อสอบ แต่อาจยังมีข้อมูลตกหล่นได้ จึงควรตรวจและแก้ไข JSON ที่ AI สร้างก่อนบันทึก ระบบตรวจตัวเลือกและเฉลยซ้ำ เกมจะถูกบันทึกเป็นฉบับร่างและไม่เผยแพร่เอง หาก Ollama ไม่ทำงานหรือสร้างข้อมูลไม่ถูกต้อง ระบบจะแสดงข้อผิดพลาดและไม่บันทึกร่าง

ตรวจสอบ API ได้ที่ `http://127.0.0.1:8000/docs` และรันทดสอบด้วย:

```powershell
python -m unittest backend.tests.test_api
```

### ขอบเขตและข้อควรระวัง

- SQLite ในระยะนี้เก็บข้อมูลถาวรบนเครื่องที่รัน Backend เท่านั้น ยังไม่ซิงก์ข้ามเครื่อง
- GitHub Pages ยังคงใช้พื้นที่จัดเก็บของเบราว์เซอร์ จนกว่าจะนำ Backend ไปโฮสต์และกำหนด URL API ให้หน้าเว็บ
- API เขียนเกมต้องเข้าสู่ระบบผู้ดูแลก่อน รหัสผ่านมาจาก `BGT_ADMIN_PASSWORD`; token มีอายุ 8 ชั่วโมงและถูกยกเลิกเมื่อ Backend รีสตาร์ต
- ระบบนี้ยังไม่มี rate limiting, HTTPS หรือระบบจัดการผู้ดูแลหลายบัญชี จึงตั้งใจให้รันบน `127.0.0.1` เพื่อพัฒนาในเครื่องเท่านั้น **อย่าเปิด Backend สู่เครือข่ายสาธารณะก่อนตั้ง HTTPS, rate limiting และมาตรการ production เพิ่มเติม**
